# Цифровой двойник в Telegram

Бот входит в ваш собственный аккаунт Telegram (userbot на [Telethon](https://docs.telethon.dev))
и отвечает в выбранных чатах — личных и групповых — вашими словами. Ответы пишет Claude:
он получает описание вашей личности, примеры ваших реальных сообщений и последние
сообщения чата, а потом решает, отвечать ли и что именно.

## ⚠️ Прежде чем запускать

- **Риск блокировки.** Автоматизация личного аккаунта — серая зона правил Telegram.
  Антиспам может ограничить или заблокировать аккаунт, особенно новый или если бот пишет
  часто. Лимиты в `config.yaml` снижают риск, но не убирают его.
- **Файл `twin.session` — это полный доступ к вашему аккаунту.** Не публикуйте его, не
  отправляйте никому, не храните в открытых папках. Он уже добавлен в `.gitignore`.
  Отозвать доступ: Telegram → Настройки → Устройства → завершить сеанс.
- **Переписки уходят в Claude API.** Последние сообщения выбранных чатов и примеры из
  экспорта отправляются в Anthropic для генерации ответа.
- **Двойник не врёт, что он человек.** Если собеседник прямо и всерьёз спросит, бот ли это,
  двойник признается, что отвечает цифровой помощник. Это правило зашито в `twin/llm.py`.
- Двойник **не берёт на себя обязательства**: не соглашается на деньги, встречи и сроки
  и не передаёт коды и пароли.

## Установка

Нужен Python 3.10+.

```bash
git clone <этот репозиторий> && cd hello-world
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

### 1. Ключи

```bash
cp .env.example .env
```

- `TG_API_ID`, `TG_API_HASH` — на [my.telegram.org](https://my.telegram.org) → *API development tools*
  создайте приложение (название любое).
- `ANTHROPIC_API_KEY` — на [console.anthropic.com](https://console.anthropic.com) → *API Keys*.

### 2. Описание личности

```bash
cp persona.example.md persona.md
```

Заполните `persona.md`: кто вы, как пишете, кто ваши собеседники, что сейчас происходит
в жизни и на какие темы двойнику говорить нельзя. Двойник знает только то, что написано
здесь, — обновляйте раздел «Что сейчас происходит».

### 3. Примеры вашего стиля

В Telegram Desktop: *Настройки → Продвинутые → Экспорт данных Telegram*, отметьте
«Личные чаты» (и группы, если нужно), формат — **машиночитаемый JSON**. Затем:

```bash
python scripts/extract_examples.py путь/к/result.json --count 60
```

Скрипт сохранит в `data/examples.md` случайные фрагменты переписок, где вы отвечаете
собеседнику. **Просмотрите файл** и удалите всё лишнее: адреса, номера, личные подробности.

### 4. Чаты и поведение

```bash
cp config.example.yaml config.yaml
```

В разделе `chats` перечислите чаты: `@username`, телефон, числовой id или ссылку.
Для каждого можно задать режим:

- `all` (по умолчанию) — модель видит каждое новое сообщение и сама решает, отвечать ли;
- `mentions` — двойник реагирует, только когда вас упомянули или ответили на ваше сообщение.
  Удобно для больших групп.

Числовой id группы можно узнать, переслав сообщение из неё боту
[@userinfobot](https://t.me/userinfobot), или посмотреть в логе при запуске.

### 5. Запуск

```bash
python -m twin
```

При первом запуске Telethon спросит номер телефона, код из Telegram и пароль
двухэтапной проверки, если он есть. После этого появится файл `twin.session`, и вход
больше не понадобится.

**Начните с `dry_run: true`** (так стоит в примере): двойник будет писать в лог,
что ответил бы, но ничего не отправит. Когда ответы понравятся, поставьте `dry_run: false`.

## Управление

Пишите в «Избранное» (чат с самим собой):

| Команда | Что делает |
|---|---|
| `/twin off` | выключить двойника |
| `/twin on` | включить |
| `/twin status` | состояние и чаты на паузе |

Если вы сами написали в чат, двойник молчит в нём `pause_after_manual_minutes` минут
(по умолчанию 30), чтобы не перебивать вас.

## Как это устроено

```
twin/
  main.py      — подключение к Telegram, отслеживание чатов, задержки, «печатает…», лимиты
  llm.py       — запрос к Claude: правила, описание личности, примеры, разбор ответа
  config.py    — чтение config.yaml и .env
scripts/
  extract_examples.py — примеры стиля из экспорта Telegram
```

На каждое новое сообщение в отслеживаемом чате бот:

1. ждёт `debounce_seconds`, пока собеседник допишет серию сообщений;
2. берёт последние `history_limit` сообщений чата;
3. отправляет их в Claude вместе с описанием личности и примерами (эта часть кэшируется,
   поэтому повторные запросы дешевле);
4. получает решение: список сообщений или пустой список, если отвечать не нужно;
5. выжидает случайную паузу, показывает «печатает…» и отправляет ответ.

Модель по умолчанию — `claude-opus-5-5` с `effort: low`: для переписки этого обычно
хватает, и ответы приходят быстро. Если ответы кажутся поверхностными, поднимите `effort`
до `medium`. Если модель откажется отвечать по соображениям безопасности, запрос
автоматически перейдёт на резервную модель (`fallbacks: "default"`).

## Запуск на сервере

Двойник должен работать постоянно, поэтому удобнее держать его на VPS. Первый вход
выполните локально, затем перенесите на сервер `twin.session` вместе с `.env`,
`config.yaml`, `persona.md` и `data/` и запустите, например, через `systemd` или `tmux`.
